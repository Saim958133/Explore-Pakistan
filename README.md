Explore Pakistan 🇵🇰
Description

Explore Pakistan is a travel website showcasing Pakistan’s beautiful destinations, rich culture, history, and landscapes. It inspires visitors to discover new places, experience local traditions, and plan their next adventure.

Features
Home page with a travel-themed hero section
Popular destinations including Hunza, Skardu, Lahore, Swat, Karachi, and Islamabad
Experiences section covering adventure, culture, food, and beaches
Travel guide with useful travel tips
Image gallery
Responsive design for mobile and desktop
Smooth navigation between sections
Hover effects and modern card layouts
Technologies Used
HTML5
CSS3

How to Run
Download or clone the project.
Keep index.html and style.css in the same folder.
Open index.html in any web browser.
Make sure you have an internet connection so the online images can load.
Theme

The website uses a dark green, cream, sand, and orange color palette inspired by Pakistan’s natural landscapes and culture.
